# Connexion Atlas

Atlas est le portail de suivi des projets. En cas de problème de connexion :
1. Consulter l'état du service Atlas.
2. Si le service est dégradé, éviter les tentatives répétées et patienter.
3. Si le service est disponible, fermer la session puis réessayer dans une fenêtre privée.
4. Contacter le support si le problème persiste. Ne jamais communiquer son mot de passe.
